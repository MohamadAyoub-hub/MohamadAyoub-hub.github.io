# The Data Room

This is the full static GitHub Pages package for Mohamad Ayoub's portfolio. Copy index.html and the entire assets folder to the site root, keeping the folder paths and filename case. The site includes its copy of Three.js r187 and its MIT license.

For a local 3D preview, run python -m http.server 8000 in the extracted folder and open http://localhost:8000. Opening index.html directly displays the static scene and order outcomes.
